Courtside cricket commentary (assets/commentary/*.ogg, manifest.json)

Taken from Courtside (github.com/ali-sial-786/courtside), branch
codex/cricket-british-commentary, commit dbfa16b9 (assets/cricket/commentary/).
For this game the clips were re-encoded from Courtside's 48 kHz Ogg Vorbis q4
masters to mono 24 kHz Ogg Vorbis q2 (ffmpeg / libvorbis) to keep the download
small, and manifest.gd was converted to manifest.json (same lines and lengths).
generation.json (build provenance) is not copied.

Courtside's licence note for the bank follows.

----------------------------------------------------------------------------

Courtside cricket commentary

Kate Marsden (caller) and Geoff Hollins (summariser) are fictional characters.
All commentary and banter is original writing for Courtside.

Current bank: generated using Cartesia Sonic 3.6 through the project's Cartesia
subscription. Kate uses the Gemma library voice, and Geoff the Harrison library
voice, both native British English. These are Cartesia library voices, not
clones made from sports broadcasts. The generated audio is distributed as part
of Courtside, subject to the project's licence and the applicable Cartesia
service terms: https://cartesia.ai/terms-of-service

Every utterance has its own emotional direction. Masters are mono 48 kHz PCM,
with light EQ and compression, a soft -1.5 dBFS ceiling and Ogg Vorbis q4 output.
No synthetic room echo, pitch shifting or post-render time stretching is added.
generation.json records the precise model, cast, script and direction for each
file; manifest.gd pairs the playable clips with captions and measured lengths.
The API key and service runtime are not included in the game.

Build tools: tools/cricket/make_commentary.py and cartesia_commentary.py.
Rebuild instructions: tools/cricket/COMMENTARY.md.

Historical engines retained in the build tools (not used for the current bank):
  Chatterbox / Chatterbox Turbo by Resemble AI, code and weights MIT:
    https://github.com/resemble-ai/chatterbox
  Kokoro-82M by hexgrad, Apache-2.0, through kokoro-onnx (MIT):
    https://huggingface.co/hexgrad/Kokoro-82M
  Legacy Chatterbox references in tools/cricket/commentary_refs/:
    Cricket Hong Kong, China, Hong Kong Sixes 2025 broadcast,
    https://www.youtube.com/watch?v=biTw1GGK22o (YouTube CC BY 3.0).
    kate.flac: female caller at 6:19; geoff.flac: male summariser at 49:25.
    These references are used only when explicitly selecting the legacy
    Chatterbox engine with --refs hk. Cartesia does not read or use them.
